**Goal:** Give Claude a production brief for base/factory Roblox-ready 3D models, rigs, working moving-part animations, ammo/reload simulation, first-person/world models and portal shooter integration. This is a PROMPT + REFERENCE + SPEC package; it does **not** claim to contain the finished 21 mesh assets.

## How to use
1. Send the ZIP to Claude (or extract it into Claude's workspace).
2. Ask Claude to **read `MASTER_PROMPT_FOR_CLAUDE.md` first** and the accompanying guides and all 21 individual weapon briefs. If uploading ZIPs is unsupported, send the master prompt and then the references and data.
3. Give Claude access to your PIXELGATE Roblox Studio project and Blender/modeling tools if it can access them.
4. Request actual in-project output and evidence. Claude should create one fully working M4A1 first and then finish the other 20, not claim text-only files are the models.
